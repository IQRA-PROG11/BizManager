# 🚀 BizManager - Full Stack Management Dashboard

BizManager is a modern, full-stack MERN application designed to streamline business inventory, sales tracking, and customer management. Built with high performance and responsive user experience in mind.

---

## ✨ Features

- **Product Management:** Complete CRUD operations for adding, editing, and managing product inventory.
- **Low-Stock Alerts:** Real-time indicator banners for inventory items falling below minimum thresholds.
- **Sales & Customer Tracking:** Log sales transactions and maintain customer profiles seamlessly.
- **Dark Mode Support:** Built-in theme toggling for enhanced accessibility and visual comfort.
- **Live Search & Filter:** Instant search capabilities across products and records.

---

## 🛠️ Tech Stack

| Tier | Technology |
| :--- | :--- |
| **Frontend** | React (Vite), JavaScript (ES6+), CSS3 |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB Atlas (Mongoose ORM) |
| **Version Control** | Git & GitHub |

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone [https://github.com/IQRA-PROG11/BizManager.git](https://github.com/IQRA-PROG11/BizManager.git)
cd BizManager

2. Configure Backend
Bash
# Install dependencies
npm install

# Create a .env file in the root folder and add your credentials:
# MONGO_URI=your_mongodb_connection_string
# PORT=5000

# Start server
node server.js

3. Configure Frontend
Bash
# Navigate to client folder
cd client

# Install dependencies
npm install

# Start development server
npm run dev
